# Tag 100

![Godot](https://img.shields.io/badge/Godot-Engine-478CBF?logo=godot-engine&logoColor=white)

**Tag your opponent, then run away!**

Tag 100 is a two-player game where the objective is to be the first player to reach **100 points**.

Every second you spend as the runner earns you **1 point**. Once you get tagged, the other player becomes the runner and starts earning points instead.

In addition to basic movement (left, right, and jump), each player has a **boost ability** that provides 2x movement speed and a 1.5x jump boost.

You can play my game on [itch.io](https://wadwad-a.itch.io/tag-100)!

## 🎮 Controls

| Action | Player 1 | Player 2 |
|:---|:---:|:---:|
| Jump | `W` | `↑` |
| Move Left | `A` | `←` |
| Move Right | `D` | `→` |
| Activate Boost | `S` | `↓` |
